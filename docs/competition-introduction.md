# 比赛介绍页

[AstraAtmos-demo.html](../AstraAtmos-demo.html) 用于比赛现场介绍项目。页面采用正式 AstraAtmos 品牌，说明当前已开放的 Earth/Mars 大气实验流程，并提供本地观测、训练和诊断模拟器。它是独立静态 HTML，不是产品路由，也不需要安装依赖或启动后端才能观看。

## 使用

在项目目录中双击 `AstraAtmos-demo.html` 即可用 Chrome 或 Edge 打开，不需要安装依赖或启动后端。页面不请求 CDN 或在线字体；Earth 和 Mars 球体分别读取 `frontend/public/earth/blue-marble-2048.png` 与 `frontend/public/mars_texture.jpg`，转移到其他电脑时需保留这两个相对路径资源。Earth 影像仅作地理视觉参考；源影像说明见[地球底图资源](../frontend/public/earth/README.md)。

- 方向键左右：切换章节；顶部显示当前章节计数。
- F 或“全屏”按钮：进入 / 退出全屏；Esc 可退出浏览器全屏。
- Space：播放 / 暂停当前演示动画；R：重置当前章节模拟器。
- 顶部“演示模式 / 自由浏览模式”切换聚焦章节或自由滚动浏览；页面遵循系统“减少动态效果”设置。

介绍页提供九个章节：项目定位、实验链路、双星观测、观测模拟、训练模拟、预测诊断、可复核机制和技术栈、模型接入、现场演示路线。页面的观测场、训练阶段、loss、checkpoint 与诊断图均由浏览器本地生成，不访问后端，也不真的训练或推理。

## 进入产品演示

“打开分析工作台”和各路线链接指向 `http://127.0.0.1:5173/#/overview`、`#/training`、`#/predict`。先按 [README 的启动说明](../README.md#本地启动)运行产品，准备可用数据和账号下已完成的有效训练任务。预测与比较使用已训练产物；介绍页本身不会启动训练、请求数据、运行模型或登录账号。部署在其他地址时，修改介绍页中这些链接即可。

## 内容边界

- 页面上的 312.4 DU、Mars 示意读数、观测图与曲线均为演示数据并标注非实时；不是预测成绩。Earth 的 Radiation 控件只用于变量切换交互，不表示当前 MERRA-2 五变量发布含有该变量。
- Earth 活动数据为 MERRA-2 三小时发布，原生网格 240×480，总览默认 60×120；专门的昼夜周期分析尚未开放。
- Earth 官方训练模型是 DLinear；其他 Earth 模型通过独立 v1/v2 上传契约接入。Mars 模型库与上传契约保持各自适用范围。
- PFI 用于抽样范围下的输入敏感性诊断，不证明因果。科研图导出仅按已开放范围消费已有结果。
- 训练模拟器明确不会真的训练；合成训练/回测链路验证不能替代真实模型精度验收。PFI 仅表示抽样范围下的输入敏感性，不是因果解释；更多行星、无参考真值的 Earth 未来外推和混合行星数值比较没有作为已实现功能介绍。

后续改动应同时核对 [README 当前功能边界](../README.md#当前功能边界)和对应模型/数据专题，不添加未经实测的预测精度、速度、获奖或应用成果。
