# 比赛介绍页

[AstraAtmos-demo.html](../AstraAtmos-demo.html) 用于比赛现场介绍项目。页面采用正式 AstraAtmos 品牌，说明当前已开放的 Earth/Mars 大气实验流程。它是独立静态 HTML，不是产品路由，也不需要安装依赖或启动后端才能观看。

## 使用

复制 `AstraAtmos-demo.html` 到演示电脑，用 Chrome 或 Edge 打开即可。Logo、NASA 地球影像、CSS 和 JavaScript 已嵌入，不需要携带资源目录，也不请求 CDN 或在线字体。地球影像是项目 Blue Marble 纹理的正射投影，仅作地理视觉参考；页面保留 NASA / Robert Simmon / Reto Stöckli 署名，源影像说明见[地球底图资源](../frontend/public/earth/README.md)。

- 上一节 / 下一节，或方向键、PageUp / PageDown：切换章节。
- F 或“全屏”按钮：进入 / 退出全屏；Esc 可退出浏览器全屏。
- 浏览器不允许页面全屏时，使用浏览器的 F11。
- 窄屏以滚动浏览为主，保留章节计数和全屏按钮。页面遵循系统“减少动态效果”设置。

介绍页提供六个章节：项目定位、数据到预测流程、双星观测、可复核机制和技术栈、模型来源、现场演示路线。建议按观测 → 配置/已有任务 → 已训练模型预测 → 比较的顺序讲解；“四分钟”是讲解路线建议，实际训练耗时由任务与硬件决定。

## 进入产品演示

“打开分析工作台”和各路线链接指向 `http://127.0.0.1:5173/#/overview`、`#/training`、`#/predict`。先按 [README 的启动说明](../README.md#本地启动)运行产品，准备可用数据和账号下已完成的有效训练任务。预测与比较使用已训练产物；介绍页本身不会启动训练、请求数据、运行模型或登录账号。部署在其他地址时，修改介绍页中这些链接即可。

## 内容边界

- 页面上的 312.4 DU 和曲线为视觉示意，已标注为非实时；不是预测成绩。
- Earth 活动数据为 MERRA-2 三小时发布，原生网格 240×480，总览默认 60×120；专门的昼夜周期分析尚未开放。
- Earth 官方训练模型是 DLinear；其他 Earth 模型通过独立 v1/v2 上传契约接入。Mars 模型库与上传契约保持各自适用范围。
- PFI 用于抽样范围下的输入敏感性诊断，不证明因果。科研图导出仅按已开放范围消费已有结果。
- 合成训练/回测链路验证不能替代真实模型精度验收；更多行星、无参考真值的 Earth 未来外推和混合行星数值比较没有作为已实现功能介绍。

后续改动应同时核对 [README 当前功能边界](../README.md#当前功能边界)和对应模型/数据专题，不添加未经实测的预测精度、速度、获奖或应用成果。
